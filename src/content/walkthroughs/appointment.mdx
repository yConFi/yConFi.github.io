El `80` que escribí detrás de `-p-` no hace nada útil: `-p-` ya indica todos los puertos, y nmap toma ese

de los 65535 puertos solo está abierto el **80/tcp**, con un servidor web **Apache 2.4.38** en Debian.

### Fuerza bruta de directorios

Busco rutas de la web a las que no lleve ningún enlace. En una aplicación web, a una carpeta se le llama
directorio, y si la ruta pedida no existe, el servidor responde con el código **404** (*Not Found*).

<Pista titulo="Tarea 7 · ¿Cómo se llama una carpeta en la terminología de las aplicaciones web?">
  **directory** (directorio).
</Pista>

<Pista titulo="Tarea 8 · ¿Qué código de respuesta HTTP se devuelve en los errores «Not Found»?">
  **404**.
</Pista>

## Acceso inicial

Abro la web en el navegador, `http://10.129.96.48/`, y es un formulario de inicio de sesión. Como Gobuster no
encontró nada más, pruebo si el formulario es vulnerable a inyección SQL.

Si la aplicación construye la consulta a la base de datos pegando tal cual lo que se escribe en el
formulario, algo parecido a esto:

```text
SELECT * FROM users WHERE username='USUARIO' AND password='CONTRASEÑA'
```

un usuario que cierre la comilla y añada un comentario cambia la consulta. En MySQL, `#` comenta todo lo que
queda de línea.

<Pista titulo="Tarea 10 · ¿Qué carácter sirve para comentar el resto de una línea en MySQL?">
  **#**.
</Pista>

En el usuario escribo `admin'#` y en la contraseña cualquier cosa. La comilla cierra el nombre de usuario y
el `#` deja fuera la comprobación de la contraseña, así que la consulta queda, en la práctica, como:

```text
SELECT * FROM users WHERE username='admin'
```

Entra como **admin** sin conocer su contraseña, y la página que devuelve empieza por *Congratulations* y
muestra la flag.

<Pista titulo="Tarea 11 · Si lo que escribe el usuario no se trata con cuidado, se puede interpretar como un comentario. Usa un comentario para entrar como admin sin saber la contraseña. ¿Cuál es la primera palabra de la página que se devuelve?">
  **Congratulations**.
</Pista>

La flag no se publica: la tienes que conseguir tú.

<Pista titulo="Flag · Envía la flag que aparece en la página web al saltarse el inicio de sesión">
  Aparece en la página que se abre después de entrar como admin con la inyección SQL en el formulario.
</Pista>

## Escalada de privilegios

No hace falta: la flag aparece en la propia página web, sin llegar a tener una shell en la máquina.

## Lecciones aprendidas

- **Qué fallé:** perdí tiempo instalando Gobuster: probé con `apt`, con `go install` y compilándolo desde
  GitHub, cuando ya estaba instalado (la 3.6), y cloné SecLists entero (3,59 GiB) para acabar usando un
  diccionario que ya traía la Pwnbox. Además, en nmap escribí un `80` que sobraba detrás de `-p-`.
- **Lo que enseña la máquina:** un formulario que mete lo que escribe el usuario directamente en la consulta
  SQL permite saltarse el inicio de sesión con solo una comilla y un comentario.
- **Qué haré la próxima vez:** comprobar primero si una herramienta ya está instalada (con `--help` o
  `--version`) y qué diccionarios hay en `/usr/share/wordlists/` antes de descargar nada; y, ante un
  formulario de inicio de sesión, probar una inyección SQL básica como `admin'#`.
